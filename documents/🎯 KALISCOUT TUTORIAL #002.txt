📱 PART 1: INSTALLING TERMUX

Step 1: Download Official Termux

NEVER download Termux from Play Store (outdated). Use official GitHub releases.

1. Open browser → go to:
      https://github.com/termux/termux-app/releases
2. Scroll to find: v0.119.0-beta.3 (or latest stable)
3. Download the APK file:
      termux-app_v0.119.0-beta.3.apk (~119 MB)

Step 2: Install Termux APK

1. Open Downloads folder → tap the APK.
2. You'll see security warning: "Your phone currently isn't allowed to install unknown apps from this source."
3. Tap Settings → Enable "Allow from this source".
4. Go back → tap Install → wait for completion.
5. Tap Open to launch Termux.

---

🖥️ PART 2: INITIAL TERMUX SETUP

Step 3: First Launch

You'll see the Termux welcome screen:

```
Welcome to Termux!
Docs:    https://termux.dev/docs
Donate:  https://termux.dev/donate
Community: https://termux.dev/community
```

Step 4: Update Repositories

Termux needs mirror selection for reliable package downloads.

```bash
termux-change-repo
```

· Select a mirror: Choose mirrors.nguyenhoang.cloud (or any from Asia/US).
· Wait for confirmation: [*] (1) https://mirrors.nguyenhoang.cloud/termux/termux-main: ok

Step 5: Update Package Lists

```bash
pkg update
```

Wait for:

```
Fetched 576 kB in 13s (45.2 kB/s)
Reading package lists... Done
Building dependency tree... Done
7 packages can be upgraded.
```

---

📦 PART 3: INSTALL GIT

Step 6: Install Git

```bash
pkg install git
```

Expected output:

```
git is already the newest version (2.55.0).
0 upgraded, 0 newly installed, 0 to remove and 7 not upgraded.
```

🔥 Analyst Tip: Git allows cloning repositories directly to Termux – essential for security tools.

🛠️ PART 4: CLONE ZPHISHER

Step 7: Clone from GitHub

```bash

```

You'll see:

```

remote: Enumerating objects: 1801, done.
Receiving objects: 19% (343/1801)...
```

Wait for 100% completion.

Step 8: Verify Download

Check your files:

```bash

```

Output should show:


🚀 PART 5: RUN ZPHISHER

Step 9: Navigate to Directory

```bash
cd zphisher
```

Step 10: List Files

```bash
ls
```

Expected output:

```
Dockerfile  LICENSE  README.md  make-deb.sh  run-docker.sh  scripts  zphisher.sh
```

```bash

```

You'll see:

🔧 TROUBLESHOOTING

Issue Solution
Permission denied chmod +x zphisher.sh
No such file Check you're in ~/zphisher
Repo mirror fails Run termux-change-repo again
Port already in use Use kill -9 $(lsof -t -i:1234)
Browser won't connect Ensure Wi-Fi is ON, use 127.0.0.1 not localhost

---

🔄 CLEANUP

When done:

1. Press Ctrl + C in Termux to stop server.
2. Exit ZPhisher: Type 00 and Enter.
3. Exit Termux: Type exit twice.

To remove ZPhisher:

```bash
cd ~
rm -rf zphisher
```
